# CV Project Description - Event Ticket Platform

## For Your CV - Projects Section

### Option 1: Detailed Version (Recommended for Portfolio/GitHub)

**Event Ticket Platform** | [GitHub](https://github.com/amirelkased/EventTicketPlatform)
*Full-Stack Developer* | Jan 2025 - Present

A comprehensive event ticketing platform enabling organizers to create and manage events while allowing attendees to discover, purchase, and validate tickets using QR code technology.

**Key Achievements:**
- Architected and developed a full-stack application using **Spring Boot 4.0.1** (Java 21) backend and **React 19** with **TypeScript** frontend
- Implemented **OAuth 2.0/OpenID Connect** authentication with **Keycloak** for secure user management and role-based access control (RBAC)
- Designed and built RESTful APIs with **Spring Security**, **JPA/Hibernate**, and **PostgreSQL** database
- Integrated **ZXing library** for QR code generation and validation, enabling seamless ticket verification at event entrances
- Developed responsive UI using **React**, **TypeScript**, **TailwindCSS**, and **Radix UI** components (AI-assisted with custom refinements)
- Containerized infrastructure services using **Docker Compose** (PostgreSQL, Keycloak, Adminer)
- Applied enterprise design patterns including Repository, Service Layer, DTO, and Dependency Injection
- Implemented comprehensive error handling, input validation, and security best practices

**Technologies:** Java 21, Spring Boot, Spring Security, PostgreSQL, React 19, TypeScript, TailwindCSS, Keycloak, Docker, Maven, Vite, MapStruct, ZXing
